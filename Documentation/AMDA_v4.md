## Project Insights
> An ongoing DevOps project for custom application monitoring of workloads on an OpenShift-based big-data platform. The objective was to improve development and deployment processes for monitoring, alerting, and the visualization of metrics and logs, increasing the monitoring team's efficiency. The solution was rolled out to three production applications of the Data Analytics Platform; additional rollouts are ongoing or planned.



## Business Needs

#### 1. Centralized Monitoring Transparency

Create a centralized, consistent, and understandable view of system states, stability, bottlenecks, and early anomalies across interacting components.

#### 2. Faster Incident Diagnosis

Improve observability so that logs, metrics, and events can be correlated, root causes can be isolated faster, downtime can be reduced, and response coordination can be improved.

#### 3. Long-Term Operational Improvement

Provide a consistent view of operational quality, including stability, availability, performance, error frequency, and recurring anomalies, to support risk identification, prioritization, and continuous improvement.



## Provided Services
### Cloud/ onPrem: OnPrem

#### 1. Automated Deployment Pipeline

Implemented a CI/CD pipeline for the automated deployment of dashboards, alerts, and workloads, including Grafana dashboards for metrics visualization with real-time visibility into system health and resource consumption.

#### 2. Infrastructure as Code Workspace

Provided an Infrastructure-as-Code workspace with Helm packages and Docker images.

#### 3. Custom Trino Query Monitoring

Developed a custom monitoring tool for Trino queries.
